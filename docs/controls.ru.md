# Настройки: что за что отвечает

[На главную](../README.ru.md) · [English](controls.md)

Названия совпадают с интерфейсом. Шаг вещественных ползунков LOOK — **0.1**, Minimum Opacity — **0.001**. Более точное число можно ввести вручную. Существующие значения и ключи анимации не округляются.

## Новые объекты: настройки по умолчанию в 0.6.1

Сразу включён **Source Fidelity**: Maximum Splats **3 000 000**, Minimum Opacity **1/255 ≈ 0.00392157**, Camera-Facing Cards **on**, Pixel Footprint **0.075**, SH **3**, SH Strength **1**, Normal Smoothing **0**. LOOK: **sRGB Source to Scene Linear**, Highlight Limit **3**, Emission **1**, Diffuse **0**, Subsurface **0**. Global Scale **100**, Splat Scale **1** и Opacity Multiplier **1** сохранены.

Прежний лимит 262 144 мог отбрасывать большую часть подробного скана, а порог 0.02 — тонкие полупрозрачные детали. Diffuse 1 добавлял свет сцены к уже записанному цвету. Новые значения сохраняют больше исходных данных без дополнительного нажатия пресета после импорта. Команда Reset to Default использует те же значения.

**Уже созданные объекты и их копии сохраняют свои настройки.** Для старого объекта нажмите Source Fidelity, если нужен новый профиль. Кнопка сохраняет цветокоррекцию, масштаб, отражение оси и более низкий порог прозрачности. Выбранный вручную режим Colour Management она не сбрасывает.

Большой скан и обновления Camera-Facing требуют больше времени и памяти, чем уменьшенная выборка. Point Preview остаётся включённым на **10 000 точек** и облегчает только отрисовку редактора. Для черновой работы можно снизить Maximum Splats или выключить Camera-Facing Cards, пожертвовав деталями или точностью проекции; перед финалом вернуть Source Fidelity. Gaussian Count отдельно управляет AI-генерацией: лимит импорта 3 млн не создаёт дополнительные Gaussians.

## INPUT

| Настройка | Что делает |
| --- | --- |
| Input File | Выбирает фото, готовый splat, видео или один файл секвенции. Auto определяет способ обработки по расширению. |
| Input Mode | Auto — обычная загрузка; Numbered Image Sequence — работа с нумерованными файлами. |
| Source Frame / Sequence Offset | Номер кадра видео с нуля или смещение номера файла. `shot_0100.png` + 2 → `shot_0102.png`. |
| Preview Selected Frame | Открывает выбранный кадр в Picture Viewer до генерации. |
| Gaussian Count | Число создаваемых Gaussians: 65 536 / 131 072 / 262 144. Влияет только на новую AI-модель. Последнее число — предел модели TripoSplat. |
| Generation Steps | Шаги AI-сэмплинга, 1–100; по умолчанию 20. Больше шагов — дольше, улучшение не гарантируется. |
| Seed | Случайное зерно генерации. Одинаковое — для сравнения настроек; другое — для нового варианта. |
| Alpha Erosion | Сжимает маску после удаления фона. 0 сохраняет тонкие края, 1–8 могут убрать ореол, но также срезать детали. Действует при следующей генерации. |
| Output Folder | Папка результата; по умолчанию `%LOCALAPPDATA%\ArgentumSplat\generated`. Каждая задача получает отдельную подпапку. |
| Load / Generate from Input | Генерирует из фото/кадра или загружает готовый splat без AI. |
| Cancel Processing | Останавливает фоновую задачу и её дочерние процессы. Cancel и крестик окна прогресса делают то же самое. |
| Set Up AI / Extra Formats | Устанавливает отдельный AI-runtime и дополнительный конвертер. При установке нужен интернет. |
| Open Output Folder | Открывает папку результата в Проводнике. |

Окно прогресса с Cancel появляется при генерации, конвертации, первой загрузке скана, изменении исходника/параметров загрузки и явном нажатии **Initialise / Reload**. Оно охватывает **чтение SCAN, подготовку геометрии и сборку в C4D**: показывает этап, доступный прогресс и прошедшее время. Если общий объём неизвестен, отображается активность. Обычные изменения камеры и LOOK показывают ход работы в **Status**, без всплывающего окна; остановить их можно кнопкой **Cancel Processing**.

Чтение и вычисления идут в фоне; геометрия C4D собирается короткими порциями. При отмене сохраняется предыдущая готовая модель. Отдельная операция выделения памяти или записи данных C4D должна закончиться до обработки отмены.

## SCAN и качество

| Настройка | Что делает |
| --- | --- |
| Splat File | Прямой путь к скану. Загрузка начинается после остановки изменений; Initialise / Reload запускает её сразу или повторяет отменённую/неудачную попытку. Можно использовать общее поле Input File. |
| View-Dependent Colour | Off / SH1 / SH2 / SH3: цвет в зависимости от направления камеры, если коэффициенты есть в файле. TripoSplat создаёт SH0, поэтому SH-поля у таких моделей недоступны. |
| Camera-Facing Cards | Проецирует форму Gaussian на плоскость выбранной камеры. Без неё карточка ориентируется по двум главным осям Gaussian. При движении камеры требует пересчёта. |
| Projection Camera | Камера для SH и карточек. Пустая ссылка — камера рендера, затем камера редактора как запасной вариант. |
| SPZ: Unconverted Coordinates | Оставляет систему координат RUB файла SPZ. Обычный режим согласованно преобразует позиции, вращение и SH. |
| Normal Smoothing Passes | 0 отключает сглаживание; 1–8 усредняют соседние нормали. Позиции точек не размываются. У перспективных карточек к камере нормали уже одинаковы, поэтому лишний расчёт пропускается. |
| Initialise / Reload | Загружает или обновляет скан с прогрессом и Cancel. Если файл и настройки не изменились, использует готовые данные. Размер/время изменения файла и настройки загрузки обновляют соответствующий кэш. AI повторно не запускает. |
| Source Fidelity – Preserve Detail | Устанавливает Maximum Splats 3 000 000, SH3 / SH Strength 1, Emission 1, Diffuse 0, Subsurface 0 и Normal Smoothing Passes 0. Включает Camera-Facing Cards и Pixel Footprint 0.075; очищает Projection Camera, чтобы следовать текущей камере. Снижает Minimum Opacity до 1/255, если порог выше; меньший сохраняет. Запускает обновление; есть Undo. |
| Auto Prepare Redshift on Import | Включён у новых объектов. Один раз для нового пути/времени изменения/размера файла подготавливает прозрачность и сэмплинг Redshift. Маркер сохраняется в сцене: движения камеры, LOOK и повторный Reload не сбрасывают ручные настройки рендера. Можно отключить. Не меняет камеру, свет, экспозицию и управление цветом. Есть Undo. |
| Set Redshift Detail Quality | Поднимает глубину прозрачности минимум до 128, Min Samples до 16, Max Samples до 128. Выключает Automatic Sampling, чтобы эти значения действовали, и снижает порог ошибки максимум до 0.01. Более строгие настройки сохраняет. Меняет настройки документа только по нажатию; есть Undo. Может замедлить рендер. |
| Create Estimated Source Camera | Создаёт камеру по AI-метаданным `generation.json` рядом с PLY. Это оценка для квадратного `prepared.png`; положение и кадрирование могут требовать корректировки. Активную камеру не заменяет. |

Source Fidelity соответствует новому профилю качества и может требовать больше времени и памяти, чем намеренно уменьшенная выборка. SH3 использует только коэффициенты, которые уже есть в файле: у SH0-модели новые SH-данные не появятся. Кнопка не меняет исходный файл и преобразование отображения цвета документа. **Auto Prepare Redshift on Import** подготавливает глубину прозрачности и сэмплинг один раз для нового файла; отдельная кнопка **Set Redshift Detail Quality** остаётся доступной.

В **Status** указаны число загруженных splats, общее число в файле и сохранённая доля. Новый лимит — **3 000 000**; если после фильтра прозрачности остаётся больше точек, используется детерминированная выборка. В проверенном `Raspberry.sog` примерно 2,37 млн splats: при Minimum Opacity 1/255 проходят фильтр 2 309 943 точки, или 97,4% исходника. Лимит 3 млн сохраняет все прошедшие фильтр точки, без дополнительного сокращения выборкой; остальные отбрасываются порогом прозрачности. Новую шерсть, скрытую геометрию и отражения пресет не создаёт. Наложение полигональных карточек, прозрачность и управление цветом отличаются от нативного Gaussian-рендерера, поэтому полностью одинаковый результат не гарантируется.

## LOOK

| Настройка | Что делает |
| --- | --- |
| Colour Management | sRGB Source to Scene Linear декодирует sRGB исходника, учитывая явную linearRGB-метку. Treat Source as Linear считает значения линейными. Затем OCIO переводит цвет в рабочее пространство документа. Экспозиция и view transform проекта продолжают влиять на результат. |
| Highlight Limit | Верхний предел RGB после коррекции. Значения выше 1 сохраняют HDR. |
| SH Strength | Усиливает только зависимую от ракурса часть SH, не базовый SH0. |
| Emission Weight | Самосвечение. Emission 1 и Diffuse/SSS 0 сохраняют цвет скана без дополнительного освещения. |
| Diffuse Weight | Реакция на свет сцены. Увеличивайте, когда хотите освещать объект собственными источниками. |
| Subsurface Weight | Тонкостенная диффузная передача света для плоских карточек. Хорошо проверяется светом с обратной стороны. Это не объёмная физическая кожа. |

Веса хранятся в картах каждого объекта: общий материал не мешает разным значениям и анимации. Изменение только весов переиспользует геометрию, нормали и цвета. Redshift после этого заново накапливает изображение.

## COLOUR CORRECT

| Настройка | Нейтрально | Значение |
| --- | --- | --- |
| Gamma | 1 | Коррекция средних тонов. |
| Contrast | 0.5 | Контраст цвета. |
| Hue (degrees) | 0 | Сдвиг оттенка в градусах. |
| Saturation | 1 | Насыщенность; 0 убирает цвет. |
| Level | 1 | Множитель уровня цвета. |

Геометрия при цветокоррекции сохраняется, но цвета всех загруженных splats пересчитываются. Большой скан требует больше CPU-времени.

Интерактивный пересчёт начинается через **0,6 секунды после остановки изменений**. Пока вы двигаете ползунок или камеру, видна предыдущая готовая модель. Если во время расчёта меняется только камера, текущий расчёт завершается, затем обрабатывается последний запрошенный ракурс. Промежуточные положения камеры не становятся отдельными задачами в очереди. Смена исходных данных или других параметров подготовки может отменить устаревший расчёт. Ход обычного обновления виден в Status; остановить его можно через Cancel Processing.

Движение камеры не пересчитывает цвета SH0. При выключенном Camera-Facing Cards смена ракурса обновляет только цвет, если в файле есть активные SH-данные, зависящие от направления взгляда; в остальных случаях не требуется ни цветовой, ни геометрический проход. Camera-Facing всё ещё требует новой геометрии. Финальный рендер и экспорт рассчитывают запрошенную камеру и настройки без задержки интерфейса в 0,6 секунды, по возможности используя совпадающие готовые данные.

## VIEWPORT

| Настройка | Что делает |
| --- | --- |
| Point Preview | Показывает лёгкие цветные точки. IPR и финальный Redshift-рендер получают полную загруженную геометрию. |
| Preview Points (0 = All) | Ограничивает только число рисуемых точек. 0 — все загруженные точки с учётом Maximum Splats и фильтра прозрачности. Не уменьшает память полной модели. |

Для больших сканов оставьте **Point Preview включённым**, начните с **10 000 Preview Points**. Если рисование тормозит, уменьшите это число. Camera-Facing Cards off исключает перестройку геометрии при движении камеры. Maximum Splats определяет объём геометрии для рендера, Preview Points — только отрисовку редактора. При первом чтении проверяется весь исходный файл, поэтому сканы из миллионов splats всё ещё требуют времени.

При **Maximum Splats выше 262 144** плагин C4D хранит исходные записи бинарного Gaussian PLY в компактном виде. Готовые координаты, оси карточек, нормали и цвета в плагине используют компактные буферы float64. В отдельных тестовых примерах память сохраняемых Python-данных исходного облака уменьшилась примерно на **88%**, а готовых массивов — на **82,8%**. Это замеры отдельных компонентов, а не обещание такого же снижения всей памяти Cinema 4D: полигональная геометрия, материалы и рендерер по-прежнему требуют памяти.

## ADVANCED

| Настройка | Что делает |
| --- | --- |
| Global Scale | Масштаб всей модели. |
| Pixel Footprint (variance; 0 = Off) | Фильтрация размера Gaussian на изображении для Camera-Facing Cards с перспективной камерой. По умолчанию 0.075 — небольшой размер тонких деталей; 0 отключает фильтрацию. Диапазон 0–2, шаг 0.025. Более высокие значения расширяют проекции splats и могут смягчать детали. |
| Splat Scale | Размер карточек без перемещения центров. Слишком большой размывает детали; слишком маленький создаёт дырки. |
| Maximum Splats | Сохраняет не больше указанного числа splats, прошедших фильтр прозрачности; при превышении лимита делает равномерную детерминированную выборку по всему файлу. По умолчанию и максимум 3 000 000: это сохранение исходных splats, а не создание новых. Изменение параметров загрузки/фильтра запускает загрузку после остановки изменений; Initialise / Reload запускает её сразу. |
| Minimum Opacity | Отбрасывает почти прозрачные splats при загрузке. По умолчанию 1/255 (примерно 0.00392157). Меньше — больше тонких деталей и выше нагрузка. |
| Opacity Multiplier | Общий множитель прозрачности загруженных splats. |
| Flip Y Axis | Отражение по Y вместе с формой Gaussian. Для AI-результата включается автоматически, чтобы модель стояла вертикально. |
| Redshift Material | Ссылка на редактируемый узловой материал. |
| Create MoGraph Fracture Rig | Создаёт Fracture / Explode Segments. Каждая карточка — отдельный сегмент; эффекторы добавляются в Fracture. Point Preview отключается. Система координат существующих PSR-треков сохраняется. |
| Status | Ход работы, итог или текст ошибки; остаётся после закрытия окна прогресса. |
| Support the author - Boosty | Необязательная поддержка автора. Кнопка под Status открывает Boosty в браузере только по нажатию. Плагин остаётся бесплатным. |

SH и Camera-Facing вычисляются до деформеров и эффекторов, а не отдельно для каждой деформированной карточки или отражённого луча.

**Как пользоваться Pixel Footprint:** включите Camera-Facing Cards, выберите перспективную камеру и начните с **0.075**. Сравнивайте тонкие края, например волоски или стебли, при нужном разрешении итогового рендера. Значение задаёт добавочную дисперсию проекции Gaussian в квадратных пикселях, а не размер объекта в сантиметрах. Результат зависит от ракурса, объектива, выходного разрешения и соотношения сторон пикселя. Используются настройки разрешения рендера, а не размер окна вьюпорта. Для других типов проекции камеры C4D сохраняется прежний способ построения карточек. Фильтр помогает показать тонкие детали, уже содержащиеся в загруженных splats; он не дорисовывает шерсть и не восстанавливает splats, отброшенные выборкой или фильтром прозрачности.

## Перенос проекта

**Save Project with Assets** собирает скан, выбранное изображение и PLY-кэш. Всю нумерованную секвенцию переносите отдельно. Для оценочной камеры также вручную перенесите **`generation.json`** рядом с PLY. Разным исходникам в одном проекте задавайте разные имена файлов.

Для процедурного объекта на другом компьютере нужен плагин. Make Editable создаёт обычные полигональные карточки; OSL материала хранится внутри сцены. Исходный скан лучше сохранить для дальнейших изменений.

## Сравнение с Gaussian-просмотрщиком

Скан содержит позиции, форму Gaussian, прозрачность и, при наличии, SH-коэффициенты. Камера сайта, постэффекты, способ смешивания цветов и настройки движка — отдельные данные. SOG не переносит всю веб-сцену.

Сравнивайте завершённые рендеры при одинаковых камере и разрешении. Редкие точки Point Preview не означают потерю геометрии рендера. Если Projection Camera отличается от камеры рендера, Status подскажет очистить эту ссылку.

Source Fidelity использует дисперсию 0.075 в реальных пикселях: она соответствует 0.3 при удвоенных координатах проекции. Завышенное значение превращает тонкие яркие splats в крупные точки. Redshift смешивает линейный цвет и трассирует карточки; Gaussian-просмотрщик может иначе смешивать цвета, сортировать слои и рассчитывать прозрачность. Поэтому пункт Match Splat Viewer переименован в sRGB Source to Scene Linear: корректное декодирование цвета не гарантирует идентичный рендер.

### Большие сцены и проекция

Перспективные Camera-Facing Cards теперь скрывают сплаты за камерой и за границами их ограниченной проекции. Записи исходного файла остаются загруженными. Pixel Footprint **0 отключает только фильтр**, сохраняя перспективную проекцию. Размер проекции ограничен относительно разрешения кадра, чтобы точки возле плоскости камеры не создавали длинные полосы.

Карточки готовятся для одной камеры. Для перемещения MoGraph через границы кадра, зеркал и вторичных ракурсов выключите Camera-Facing Cards: сохранятся все ориентированные карточки, с менее точной проекцией. SOG не содержит полную конфигурацию камеры, фона и отображения сайта; композицию выбирают в C4D. Файлы больше лимита 3 млн могут терять детали из-за выборки.
