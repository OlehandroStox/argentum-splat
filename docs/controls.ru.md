# Настройки: что за что отвечает

## Help и упрощённые разделы

**Image** — одно фото; **Photos** — общий скан по ракурсам из папки; **Scan** — готовый Gaussian-файл. Для Photos один раз нажмите Set Up Photos, затем Reconstruct from Photos.

## Качество импорта

Новые объекты автоматически используют **MAX — Full Source**. Для быстрого черновика можно выбрать меньший **SCAN → Import Quality**. Дополнительное окно выбора качества больших файлов по умолчанию выключено.

| Пресет | Сколько сплатов загружается |
| --- | ---: |
| LOW | До 250 000 |
| MEDIUM | До 1 000 000 |
| HIGH | До 4 000 000 |
| MAX — Full Source — по умолчанию | Все сплаты, прошедшие фильтр прозрачности |

**Import Budget** показывает количество в исходнике, предел выбранного режима и приблизительный дополнительный расход RAM. Это не замер видеопамяти. При недостатке свободной RAM загрузка останавливается с объяснением; MAX не подменяется уменьшенной выборкой. Флажок **Ask for Large Files** запоминается для объекта. Cancel закрывает окно выбора без тяжёлого расчёта; во время обработки также остаются прогресс, отмена и предыдущая готовая модель.

Пресеты управляют существующим **Maximum Splats**: **0 — весь исходник**. Ручной лимит отображается как CUSTOM. Старые сцены сохраняют свои лимиты. **Source Fidelity** больше не меняет выбранное количество. **SH 1–3** управляет цветом при смене ракурса, а **Preview Points** — только точками во вьюпорте. LOW сокращает подготовку геометрии, но файл всё равно проверяется целиком. MAX ограничен ресурсами ПК и защитным пределом входного файла в 100 млн записей, а не прежним ограничением загруженных данных в 4 млн.

Внизу Help находятся версия и кнопка Boosty. Open Help Reader открывает отдельное окно с изменяемым размером.

Названия совпадают с интерфейсом. Шаг вещественных ползунков LOOK — **0.1**, Minimum Opacity — **0.001**. Более точное число можно ввести вручную. Существующие значения и ключи анимации не округляются.

## Новые объекты: настройки по умолчанию

Сразу включён **Source Fidelity**: Maximum Splats **0 (Full Source)**, Minimum Opacity **1/255 ≈ 0.00392157**, Camera-Facing Cards **on**, Pixel Footprint **0.075**, SH **3**, SH Strength **1**, Normal Smoothing **0**. LOOK: **sRGB Source to Scene Linear**, Highlight Limit **3**, Emission **1**, Diffuse **0**, Subsurface **0**. Global Scale **100**, Splat Scale **1** и Opacity Multiplier **1** сохранены.

**Уже созданные объекты и их копии сохраняют свои настройки.** Для старого объекта нажмите Source Fidelity, если нужен новый профиль. Кнопка сохраняет цветокоррекцию, масштаб, отражение оси и более низкий порог прозрачности. Выбранный вручную режим Colour Management она не сбрасывает.

Большой скан и обновления Camera-Facing требуют больше времени и памяти, чем уменьшенная выборка. Point Preview у новых объектов включён на **50 000 точек** и облегчает только отрисовку редактора. Для черновой работы можно снизить Maximum Splats или выключить Camera-Facing Cards, пожертвовав деталями или точностью проекции; перед финалом выбрать HIGH или MAX. Gaussian Count отдельно управляет AI-генерацией: лимит импорта не создаёт дополнительные Gaussians.

Окно прогресса с Cancel появляется при генерации, конвертации, первой загрузке скана, изменении исходника/параметров загрузки и явном нажатии **Initialise / Reload**. Оно охватывает **чтение SCAN, подготовку геометрии и сборку в C4D**: показывает этап, доступный прогресс и прошедшее время. Если общий объём неизвестен, отображается активность. Обычные изменения камеры и LOOK показывают ход работы в **Status**, без всплывающего окна; остановить их можно кнопкой **Cancel Processing**.

Чтение и вычисления идут в фоне; геометрия C4D собирается короткими порциями. При отмене сохраняется предыдущая готовая модель. Отдельная операция выделения памяти или записи данных C4D должна закончиться до обработки отмены.

## SCAN и качество

| Splat File | Прямой путь к скану. Загрузка начинается после остановки изменений; Initialise / Reload запускает её сразу или повторяет отменённую/неудачную попытку. |
| View-Dependent Colour | Off / SH1 / SH2 / SH3: цвет в зависимости от направления камеры, если коэффициенты есть в файле. TripoSplat создаёт SH0, поэтому SH-поля у таких моделей недоступны. |
| Camera-Facing Cards | Проецирует форму Gaussian на плоскость выбранной камеры. Без неё карточка ориентируется по двум главным осям Gaussian. При движении камеры требует пересчёта. |
| Projection Camera | Камера для SH и карточек. Пустая ссылка — камера рендера, затем камера редактора как запасной вариант. |
| SPZ: Unconverted Coordinates | Оставляет систему координат RUB файла SPZ. Обычный режим согласованно преобразует позиции, вращение и SH. |
| Normal Smoothing Passes | 0 отключает сглаживание; 1–8 усредняют соседние нормали. Позиции точек не размываются. У перспективных карточек к камере нормали уже одинаковы, поэтому лишний расчёт пропускается. |
| Initialise / Reload | Загружает или обновляет скан с прогрессом и Cancel. Если файл и настройки не изменились, использует готовые данные. Размер/время изменения файла и настройки загрузки обновляют соответствующий кэш. AI повторно не запускает. |
| Source Fidelity – Preserve Detail | Сохраняет лимит импорта; устанавливает SH3 / SH Strength 1, Emission 1, Diffuse 0, Subsurface 0 и Normal Smoothing Passes 0. Включает Camera-Facing Cards и Pixel Footprint 0.075; очищает Projection Camera, чтобы следовать текущей камере. Снижает Minimum Opacity до 1/255, если порог выше; меньший сохраняет. Запускает обновление; есть Undo. |
| Auto Prepare Redshift on Import | Включён у новых объектов. Один раз для нового источника подготавливает прозрачность и сэмплинг Redshift. При первом SOG-импорте в пустую сцену заменяет стандартный ACES view на Un-tone-mapped для сохранения захваченных цветов. Готовые сцены и нестандартные view сохраняются. Маркер защищает последующие ручные настройки от сброса при движении камеры, LOOK и Reload. Можно отключить. Свет, экспозиция и рабочее цветовое пространство не меняются. Есть Undo. |
| Auto Frame in Empty Scene | Включён у новых объектов. При первом импорте нового файла создаёт камеру, если в сцене только этот Splat и нет пользовательской камеры или Projection Camera. Кадр и ближняя плоскость отсечения зависят от размера модели. Если есть подходящие метаданные AI, используется исходный ракурс. При смене файла можно повторно использовать созданную камеру, пока её не правили вручную. Геометрия, единицы и оси не меняются. |
| Frame Loaded Scan | Создаёт и включает отдельную редактируемую камеру для загруженной модели. Старые камеры сохраняются. Подготавливает проекцию из уже прочитанных данных без повторного чтения файла. |
| Set Redshift Detail Quality | Поднимает глубину прозрачности минимум до 128, Min Samples до 16, Max Samples до 128. Выключает Automatic Sampling, чтобы эти значения действовали, и снижает порог ошибки максимум до 0.01. Более строгие настройки сохраняет. Меняет настройки документа только по нажатию; есть Undo. Может замедлить рендер. |
| Create Estimated Source Camera | Создаёт камеру по AI-метаданным `generation.json` рядом с PLY. Это оценка для квадратного `prepared.png`; положение и кадрирование могут требовать корректировки. Активную камеру не заменяет; без соответствующих AI-метаданных кнопка недоступна. |

Source Fidelity соответствует новому профилю качества и может требовать больше времени и памяти, чем намеренно уменьшенная выборка. SH3 использует только коэффициенты, которые уже есть в файле: у SH0-модели новые SH-данные не появятся. Кнопка не меняет исходный файл и преобразование отображения цвета документа. **Auto Prepare Redshift on Import** подготавливает глубину прозрачности и сэмплинг один раз для нового файла; отдельная кнопка **Set Redshift Detail Quality** остаётся доступной.

## LOOK

| Colour Management | sRGB Source to Scene Linear декодирует sRGB исходника, учитывая явную linearRGB-метку. Treat Source as Linear считает значения линейными. Затем OCIO переводит цвет в рабочее пространство документа. Экспозиция и view transform проекта продолжают влиять на результат. |
| Highlight Limit | Верхний предел RGB после коррекции. Значения выше 1 сохраняют HDR. |
| SH Strength | Усиливает только зависимую от ракурса часть SH, не базовый SH0. |
| Emission Weight | Самосвечение. Emission 1 и Diffuse/SSS 0 сохраняют цвет скана без дополнительного освещения. |
| Diffuse Weight | Реакция на свет сцены. Увеличивайте, когда хотите освещать объект собственными источниками. |
| Subsurface Weight | Тонкостенная диффузная передача света для плоских карточек. Хорошо проверяется светом с обратной стороны. Это не объёмная физическая кожа. |

Веса хранятся в картах каждого объекта: общий материал не мешает разным значениям и анимации. Изменение только весов переиспользует геометрию, нормали и цвета. Redshift после этого заново накапливает изображение.

## COLOUR CORRECT

| Настройка | Нейтрально | Значение |
| --- | --- | --- |
| Gamma | 1 | Коррекция средних тонов. |
| Contrast | 0.5 | Контраст цвета. |
| Hue (degrees) | 0 | Сдвиг оттенка в градусах. |
| Saturation | 1 | Насыщенность; 0 убирает цвет. |
| Level | 1 | Множитель уровня цвета. |

Геометрия при цветокоррекции сохраняется, но цвета всех загруженных splats пересчитываются. Большой скан требует больше CPU-времени.

Интерактивный пересчёт начинается через **0,6 секунды после остановки изменений**. Пока вы двигаете ползунок или камеру, видна предыдущая готовая модель. Если во время расчёта меняется только камера, текущий расчёт завершается, затем обрабатывается последний запрошенный ракурс. Промежуточные положения камеры не становятся отдельными задачами в очереди. Смена исходных данных или других параметров подготовки может отменить устаревший расчёт. Ход обычного обновления виден в Status; остановить его можно через Cancel Processing.

Движение камеры не пересчитывает цвета SH0. При выключенном Camera-Facing Cards смена ракурса обновляет только цвет, если в файле есть активные SH-данные, зависящие от направления взгляда; в остальных случаях не требуется ни цветовой, ни геометрический проход. Camera-Facing всё ещё требует новой геометрии. Финальный рендер и экспорт рассчитывают запрошенную камеру и настройки без задержки интерфейса в 0,6 секунды, по возможности используя совпадающие готовые данные.

## VIEWPORT

| Point Preview | Показывает лёгкие цветные точки. IPR и финальный Redshift-рендер получают полную загруженную геометрию. |
| Preview Points (0 = All) | Ограничивает только число рисуемых точек. 0 — все загруженные точки с учётом Maximum Splats и фильтра прозрачности. Не уменьшает память полной модели. |

Для больших сканов оставьте **Point Preview включённым**, начните с новых **50 000 Preview Points**. Если рисование тормозит, уменьшите это число. Camera-Facing Cards off исключает перестройку геометрии при движении камеры. Maximum Splats определяет объём геометрии для рендера, Preview Points — только отрисовку редактора. При первом чтении проверяется весь исходный файл, поэтому сканы из миллионов splats всё ещё требуют времени.

## ADVANCED

| Global Scale | Масштаб всей модели. |
| Pixel Footprint (variance; 0 = Off) | Фильтрация размера Gaussian на изображении для Camera-Facing Cards с перспективной или параллельной камерой. По умолчанию 0.075. Расширяет мелкие splats и компенсирует непрозрачность в центре с учётом добавленной площади; 0 отключает оба действия. Диапазон 0–2, шаг 0.025. Более высокие значения могут смягчать детали. |
| Splat Scale | Размер карточек без перемещения центров. Слишком большой размывает детали; слишком маленький создаёт дырки. |
| Maximum Splats | Сохраняет не больше указанного числа splats, прошедших фильтр прозрачности; при превышении лимита делает равномерную детерминированную выборку по всему файлу. По умолчанию 0 — весь исходник: это сохранение исходных splats, а не создание новых. Изменение параметров загрузки/фильтра запускает загрузку после остановки изменений; Initialise / Reload запускает её сразу. |
| Minimum Opacity | Отбрасывает почти прозрачные splats при загрузке. По умолчанию 1/255 (примерно 0.00392157). Меньше — больше тонких деталей и выше нагрузка. |
| Opacity Multiplier | Общий множитель прозрачности загруженных splats. |
| Flip Y Axis | Отражение по Y вместе с формой Gaussian. Для AI-результата включается автоматически, чтобы модель стояла вертикально. |
| Redshift Material | Ссылка на редактируемый узловой материал. |
| Create MoGraph Fracture Rig | Создаёт Fracture / Explode Segments. Каждая карточка — отдельный сегмент; эффекторы добавляются в Fracture. Point Preview отключается. Система координат существующих PSR-треков сохраняется. |
| Status | Ход работы, итог или текст ошибки; остаётся после закрытия окна прогресса. |
| Support the author - Boosty | Необязательная поддержка автора. Кнопка под Status открывает Boosty в браузере только по нажатию. Плагин остаётся бесплатным. |

SH и Camera-Facing вычисляются до деформеров и эффекторов, а не отдельно для каждой деформированной карточки или отражённого луча.

**Как пользоваться Pixel Footprint:** включите Camera-Facing Cards, выберите обычную или нативную Redshift-камеру с перспективной либо параллельной проекцией и начните с **0.075**. Сравнивайте тонкие края, например волоски или стебли, при нужном разрешении итогового рендера. Значение задаёт добавочную дисперсию проекции Gaussian в квадратных пикселях, а не размер объекта в сантиметрах. Результат зависит от ракурса, объектива, выходного разрешения и соотношения сторон пикселя. Film Offset / RS Sensor Shift смещает и область кадра, по которой отбрасываются невидимые карточки. Параллельные камеры используют постоянное направление SH, в том числе при выключенных Camera-Facing Cards. Используются настройки разрешения рендера, а не размер окна вьюпорта. Для фиксированных видов спереди/сбоку, косоугольных и других непроверенных типов проекции сохраняется прежний способ построения карточек. Фильтр помогает показать тонкие детали, уже содержащиеся в загруженных splats; он не дорисовывает шерсть и не восстанавливает splats, отброшенные выборкой или фильтром прозрачности.

## Перенос проекта

**Save Project with Assets** собирает скан, выбранное изображение и PLY-кэш. Всю нумерованную секвенцию переносите отдельно. Для оценочной камеры также вручную перенесите **`generation.json`** рядом с PLY. Разным исходникам в одном проекте задавайте разные имена файлов.

Для процедурного объекта на другом компьютере нужен плагин. Make Editable создаёт обычные полигональные карточки; OSL материала хранится внутри сцены. Исходный скан лучше сохранить для дальнейших изменений.

## Внешний вид и скорость

Скан содержит форму, цвет и прозрачность. Камера сайта, фон и постэффекты — отдельные настройки. Redshift использует полигональные карточки и может отличаться от Gaussian-просмотрщика. Сравнивайте готовые рендеры с одинаковыми камерой и разрешением.

Введённый в 0.8.2 профиль прозрачности соответствует нормализованному Gaussian falloff SuperSplat. В 0.8.3 при включённом Pixel Footprint непрозрачность дополнительно компенсируется по отношению исходной и расширенной площади проекции. Это уменьшает избыточную яркость очень мелких splats, сохраняя исходные RGB и SH; крупные различимые splats затрагиваются значительно меньше. Pixel Footprint 0 отключает и фильтр, и компенсацию. Старые сцены с включённым фильтром после обновления могут выглядеть иначе.

Исходные встроенные шейдеры обновляются, пользовательский код сохраняется. Различия в пространстве смешивания цвета, ограниченная глубина прозрачности и пересечения близких карточек по-прежнему ограничивают визуальное совпадение. Подробнее: [совместимость рендеринга](rendering-compatibility.ru.md).

Camera-Facing Cards рассчитываются для одной камеры. Для MoGraph с перемещением через границы кадра, зеркал и других ракурсов выключите эту опцию: сохранятся ориентированные карточки, но проекция будет менее точной. Во время обновления IPR может показывать предыдущий ракурс; дождитесь **Ready**.

HIGH сохраняет до 4 млн сплатов; MAX — все прошедшие фильтр прозрачности. Уменьшайте Import Quality для снижения расхода памяти и времени подготовки, Preview Points — для ускорения рисования в редакторе. Это разные этапы работы.

## Автоматический кадр и Source Summary

Автокадрирование подбирает обзор основной области скана, уменьшая влияние протяжённого дальнего фона без удаления данных. Для обычного SOG детальное заполнение кадра возле начала координат позволяет выбрать внутренний начальный вид. Камеры пользователя сохраняются. Это геометрическая оценка, а не восстановление отсутствующих данных исходной камеры.

**Source Summary** показывает загруженное/исходное число сплатов, степень SH, цветовое пространство и сокращение данных фильтром или лимитом. Это не оценка качества реконструкции.

**Auto SOG Orientation** переводит обычную для SOG ось Y вниз в Y вверх Cinema 4D. Старые сцены сохраняют свою ориентацию. Для заранее переориентированного SOG отключите опцию. **Flip Y Axis** остаётся дополнительным переключателем.

## Photos

PHOTOS — ОБЩИЙ СКАН ПО НЕСКОЛЬКИМ РАКУРСАМ

Photos Folder — папка со снимками одного неподвижного объекта или места. JPG, PNG, WebP, TIFF и BMP прямо в папке, без подпапок. Минимум 3, максимум 500. Начните с 10–50 резких перекрывающихся ракурсов. Перемещайте камеру, сохраняя объект и освещение неподвижными. Разные объекты, копии, смаз, отражения, прозрачность и отсутствие перекрытия мешают совмещению.

Set Up Photos устанавливает отдельные Python, PyCOLMAP и Brush (примерно 250 МБ). Веса Image не нужны. Определение камер на CPU, коррекция объектива и обучение Gaussian на GPU идут локально. Снимки никуда не отправляются. Brush нужен совместимый GPU и актуальный драйвер; расход памяти зависит от разрешения и числа точек.

Training Steps по умолчанию 30 000. Maximum Gaussians по умолчанию 1 000 000 — верхний предел, а не обещанное число точек. Photo Resolution — длинная сторона рабочих копий; оригиналы не меняются. Начните со стандартных настроек и Reconstruct from Photos. Во время обучения отображаются прошедшее время и заданное число шагов, а не выдуманный процент.

Cancel Processing останавливает процессы и сохраняет предыдущий скан. Каждый результат — в новой папке. Готовый PLY импортируется автоматически, если выбор исходников не изменился. alignment.json перечисляет использованные и пропущенные снимки: совместиться должны минимум 60% и минимум 3. Пропуски могут оставить дыры. generation.json содержит оценённую камеру одного ракурса; масштаб условный. Переносите его рядом с PLY. Для повторного расчёта сохраните папку оригинальных фотографий отдельно.

## 0.9.2 — Photos colour

Training Colour: Redshift - Linear использует линейные 16-битные копии без потерь. Splat Viewers - sRGB сохраняет обычное отображение во внешних просмотрщиках. Для определения камер используются обычные фотографии. Цветовое пространство и профиль Brush записываются в PLY и учитываются автоматически. Старые sRGB-сканы нужно пересчитать для полного улучшения цвета.

Для Photos стандартный Pixel Variance автоматически становится 0.3, как при обучении; у обычных импортированных сканов остаётся 0.075. Явно заданные нестандартные значения сохраняются. Само увеличение Maximum Gaussians не гарантирует резкость: детали также зависят от разрешения обработки, точности камер и перекрытия снимков. Проверяйте несколько сохранённых ракурсов и соседние положения камеры.
